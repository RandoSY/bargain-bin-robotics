Robot8051 ESP32-C3 BLE Dashboard

Chrome Web Bluetooth control panel for an 8051 two-wheel robot using an ESP32-C3 Nordic UART Service bridge.

Connection

Disconnected
Use Chrome on a computer or Android device with Web Bluetooth enabled. The ESP32-C3 should advertise as Robot8051-C3. BLE writes go to the 8051 UART; 8051 UART text is returned as BLE notifications.
